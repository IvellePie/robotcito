# Robot OLED 
## Español
Un robot que usa dos pequeñas pantallas como ojos y un motor para moverse. Esta conectado a bluetooth y se puede controlar usando comandos sencillos desde cualquier telefono
### Componentes 
* Micro servo (9g)
* Esp32 DEVKI TV1
* Bateria (9V)
* 2 pantallas OLED SSD1306 (I2C)
* Cables Macho-Hembra y Hembra-Hembra
### Librerias
* `Adafruit_SSD1306`
* `Adafruit_GFX`
* `ESP32Servo`
## English
A robot that uses two screens as eyes and a motor to move. It is conected to bluetooth and it can be controled using simle commands from any phone.
### Hardware Components
* ESP32 DEVKIT V1
* 2x SSD1306 OLED Displays (I2C)
* Micro Servo SG90 (9g)
* Battery (9V)
